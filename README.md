# TarkovMapTool

### 塔科夫地圖查看器－小夥伴專用版 V3.0

為《逃離塔科夫》玩家打造的 Windows 地圖查看小工具。使用本機地圖圖片，搭配自由拖曳、搜尋收藏、透明覆蓋層與四角輔助瞄準框，方便在遊戲前查閱地圖，或在遊戲中快速切換查看。

採用深色介面與自訂頂部列，程式以**單一 EXE** 提供，不需另外安裝 Python。**地圖放在外部 `maps` 資料夾**，可以自行新增與替換，無須等待程式更新。

第一次使用，請下載程式並準備地圖圖片。可使用上方地圖包，也可以放入自己整理的地圖；**不必備齊所有地圖才能使用**。

地圖圖片不包含在 EXE 內。圖片上的撤離點、任務、鑰匙與其他標示，以各張地圖素材的內容及版本為準。

## 快速開始

1. 從 Releases 下載 `TarkovMapTool.exe`，放進一個可寫入的資料夾。
2. 下載 Maps 地圖包並解壓縮，將地圖圖片或分類資料夾放進 EXE 旁的 `maps` 資料夾。
3. 開啟程式，在左側地圖資料庫選取圖片。
4. 使用滑鼠拖曳移動圖片、滾輪縮放；雙擊圖片區域可恢復完整顯示。
5. 需要遊戲中查看時，按「開啟覆蓋層」或 `Home`；按 `Insert` 切換滑鼠穿透。

資料夾範例：

```text
TarkovMapTool/
├─ TarkovMapTool.exe
├─ maps/
│  ├─ 海關/
│  │  └─ 海關地圖.jpg
│  ├─ 森林/
│  │  └─ 森林地圖.png
│  └─ 儲備站/
│     ├─ 地面地圖.jpg
│     └─ 地下地圖.png
└─ settings.json
```

`settings.json` 會在程式正常關閉時自動儲存，不需要手動建立。若 `maps` 不存在，程式會建立空資料夾；放入圖片後按「重新掃描」即可載入。

## 功能介紹

### 地圖資料庫

- **資料夾分類**：掃描 `maps` 及其子資料夾，依圖片所在資料夾整理清單。
- **快速搜尋**：輸入圖片名稱或分類名稱，立即篩選符合的地圖。
- **收藏常用地圖**：選取圖片後按「收藏地圖」，再使用左側「收藏」篩選。
- **圖片資訊**：名稱右側顯示分類、解析度與檔案格式。
- **隨時更新素材**：新增、替換或移除圖片後，按「重新掃描」更新清單；替換目前正在顯示的同名圖片後，可重新啟動程式，確保讀取新內容。
- **快速開啟資料夾**：透過「開啟地圖資料夾」直接管理本機圖片。

支援格式：**PNG、JPG、JPEG、BMP、WebP**。

### 地圖查看與自由拖曳

- 按住滑鼠左鍵拖曳圖片，使用滾輪或工具列的 `＋`、`−` 縮放。
- **圖片到達邊界後仍可繼續拖曳**，方便將地圖邊緣的資訊移到畫面中央。
- 雙擊地圖區域或按「完整顯示」，快速找回整張圖片。
- 主視窗會記住各張地圖的縮放比例與瀏覽位置，切回時可接續查看。
- 將分類及解析度整合到名稱右側，減少上方資訊占用的空間。

### 遊戲覆蓋層

覆蓋層是獨立的置頂地圖視窗，可以自行拖曳位置、調整大小，並以 **20%～100%** 的透明度顯示。

| 操作模式 | 用途 |
| --- | --- |
| 可操作模式 | 拖曳、縮放地圖，調整覆蓋層位置與大小 |
| 滑鼠穿透模式 | 滑鼠操作傳遞至下方視窗，方便繼續操作遊戲 |

- `Home`：開啟或隱藏地圖覆蓋層，需先選取地圖。
- `Insert`：在覆蓋層顯示時，切換可操作／滑鼠穿透模式。
- 再次開啟覆蓋層會先恢復可操作模式。
- 切換地圖時，請回主視窗選取圖片，覆蓋層會同步載入。
- 主視窗另有「視窗置頂」開關，可與覆蓋層分別使用。

### 四角輔助瞄準框

保留原版螢幕中央的四角向內框線。點擊地圖工具列上的「輔助瞄準框」展開設定，再勾選啟用。

| 設定 | 可調整內容 |
| --- | --- |
| 顏色 | 紅色、綠色、藍色、黃色 |
| 線長 | 8～100 |
| 粗細 | 1～10 |
| 間距 | 0～500，預設 250；代表螢幕中心到角落的水平／垂直距離 |
| 顯示螢幕 | 主要螢幕或指定螢幕 |

- 使用**滑桿或直接輸入數字**調整，不設加減按鈕。
- `F8` 可快速開關，覆蓋層底部也有同步開關。
- 瞄準框保持置頂並讓滑鼠穿透，獨立於地圖覆蓋層運作。
- 顏色、尺寸、螢幕與啟用狀態會保存；關閉程式時，瞄準框也會關閉。
- `Home` 只控制地圖覆蓋層，關閉瞄準框請使用 `F8` 或取消勾選。
- 系統顯示縮放比例會影響框線實際顯示大小。

### 偏好設定與版本檢查

- 保存收藏、最後選取的地圖、主視窗地圖瀏覽位置、覆蓋層透明度與視窗位置／大小。
- 保存輔助瞄準框設定，重新啟動後沿用。
- 啟動時自動檢查版本，也可按左側「檢查版本更新」。
- 發現較新版本時，顯示版本號與更新說明，選擇「前往下載」後開啟下載網址。
- 連線失敗時顯示錯誤原因，可稍後重試；**本機地圖瀏覽仍可離線使用**。

版本檢查提供更新通知與下載入口，**不會自動覆寫程式**。

## 快捷鍵一覽

| 快捷鍵／滑鼠操作 | 功能 | 使用範圍 |
| --- | --- | --- |
| `Home` | 開啟／隱藏地圖覆蓋層 | 程式執行期間，全域生效 |
| `Insert` | 切換覆蓋層滑鼠穿透 | 覆蓋層顯示時，全域生效 |
| `F8` | 開啟／關閉輔助瞄準框 | 程式執行期間，全域生效 |
| `Ctrl + F` | 聚焦地圖搜尋欄 | 主視窗 |
| `Ctrl + D` | 收藏／取消收藏目前地圖 | 主視窗 |
| `Ctrl + R` | 重新掃描地圖清單 | 主視窗 |
| `F` | 完整顯示地圖 | 主視窗 |
| `＋`／`−` | 放大／縮小地圖 | 主視窗 |
| 滑鼠左鍵拖曳 | 自由平移地圖 | 主視窗及覆蓋層 |
| 滾輪 | 縮放地圖 | 主視窗及覆蓋層 |
| 雙擊地圖區域 | 完整顯示地圖 | 主視窗及覆蓋層 |

輸入文字或數字時，部分按鍵由輸入欄位處理；可使用「完整顯示」按鈕重置地圖。

## 更新程式與地圖

### 更新程式

1. 關閉正在執行的 TarkovMapTool。
2. 從 Releases 下載新版 EXE。
3. 替換原有 `TarkovMapTool.exe`。
4. 保留同目錄的 `maps` 與 `settings.json`，再開啟程式。

### 更新地圖

將新版圖片放進 `maps`，再按「重新掃描」。地圖檔案由使用者自行管理，程式更新不需要重新下載整包地圖；移動或更名圖片後，原有收藏及瀏覽位置不會自動對應新路徑。

## 使用環境

- Windows 64 位元；目前已在 Windows 11 驗證。
- 使用發布版 EXE 不需另外安裝 Python。
- 程式資料夾需可寫入，才能建立地圖資料夾並保存偏好設定。
- 建議遊戲使用**無邊框視窗模式**；獨佔全螢幕可能無法顯示桌面覆蓋層或瞄準框。
- 單一 EXE 啟動時會先解壓執行元件，可能需要稍候。

## 常見問題

### 開啟後沒有地圖？

確認 `maps` 與 EXE 位於同一層，而且地圖包已解壓縮成圖片。程式不會直接讀取 ZIP／RAR 壓縮檔。按「重新掃描」，並確認搜尋欄與收藏篩選沒有隱藏地圖。

### 地圖被拖出畫面，找不到了？

雙擊地圖區域或按「完整顯示」，即可重新置中顯示整張圖片。

### 覆蓋層無法點擊或拖曳？

可能處於滑鼠穿透模式，按 `Insert` 恢復操作；也可按 `Home` 隱藏後重新開啟。

### 地圖覆蓋層關閉了，瞄準框為什麼還在？

兩者為獨立開關。按 `F8` 關閉瞄準框，或在設定面板取消勾選。完全結束程式會一併關閉兩者。

### 修改數值後，下次還需要重設嗎？

正常關閉程式時會將偏好寫入 `settings.json`。請保留這個檔案，並確認程式資料夾有寫入權限。

### 版本檢查失敗，還能使用嗎？

可以。本機圖片不依賴更新伺服器。稍後確認網路連線，再按「檢查版本更新」即可。

### 可以在地圖上畫線或放圖釘嗎？

V3.0 不提供地圖繪圖、路線或圖釘功能，主要用途是圖片查看與輔助顯示。
